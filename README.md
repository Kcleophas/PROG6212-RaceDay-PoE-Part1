# RaceDay Event Management System

## PROG6212 Programming 2B - PoE Part 1

### Project Description

RaceDay is a web-based event management system designed to support running, walking and cycling events in South Africa.

The system allows Organisers to create and manage events, categories, participant enrolments and race results. Participants can create accounts, browse available events, enter events and view their own results.

### User Roles

#### Organiser

An Organiser can:

- Create, edit and delete events.
- Manage event categories.
- View participant enrolments.
- Capture race results.
- View information about events they manage.

#### Participant

A Participant can:

- Create an account and log in.
- Browse available events.
- Enter an event.
- Select a category.
- View their enrolments.
- View their race results and performance history.
